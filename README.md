# TecnoStock – Sistema de inventario (PHP 8 + PDO + MySQL + Bootstrap 5)

## Instalación en XAMPP
1. Copiar la carpeta `tecnostock` a `C:\xampp\htdocs\`.
2. Iniciar Apache y MySQL en XAMPP.
3. phpMyAdmin → Importar → `tecnostock.sql`.
4. Abrir http://localhost/tecnostock/ — usuario `admin@tecnostock.cl`, clave `Admin123*`.
5. Si MySQL tiene clave, editar `config/conexion.php`.

Documentación: carpeta `docs/` (análisis, modelo, pruebas, git, guion).
